## Changes

- Apply/clear/type changes refresh checkout totals immediately; invalid/nonfinite discounts and percentages above 100 are rejected.
- Reset clears discount/reason, note fields, backdate/date/time and payment selection. Unresolved recovery keeps the basket; verified recovery resets it.
- Pending/recovery state disables controls and guards mutation handlers, including another tab's pending journal. A completed sale in another tab no longer clears an unrelated unsent basket.
- Receipt pickup, note, discount metadata and grouped lines come from the same pre-await snapshot as the submitted request. Atomic sale client, journal, receipt verification and transport remain unchanged.
- Order history uses DOM/textContent, with no interpolated inline order actions. Legacy cancel writes are removed; mobile explains that refunds must use the supported main-web orders page. This candidate does not implement a new mobile refund flow.
- Loading/error/offline/empty menu states and retry preserve the basket; checkout remains blocked before a valid menu snapshot. Read-only shared menu-insights ranking uses existing semantics and freezes after interaction. Recommended items are labelled ร้านแนะนำ.
- Zoom is enabled, quantity targets are at least 44px, small-screen product cards use two rows, short screens compact the header, dialogs scroll, cart is keyboard-operable, dialogs trap/return focus and support Escape. Offscreen images are lazy loaded.

Limits: desktop Chrome viewport emulation, not physical Android or iOS Safari; native keyboards and pinch gestures are not verified. Cross-tab journal state is injected rather than a full two-browser checkout. Long modifier lists, offline/reconnect timing under real transport and independent QA remain to be checked. No production endpoint is exercised by this browser suite. Full hosted source is wrapped/patched; review runtime overrides in addition to source patches. Manual staging deployment and independent QA are required before considering production rollout.
